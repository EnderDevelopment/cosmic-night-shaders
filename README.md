# Cosmic Night Shaders

Cosmic Night Shaders is a Minecraft plugin that enhances the night sky with stunning visual effects, including glowing halos around celestial bodies and a mesmerizing black hole in the End dimension. This plugin is designed to create a more immersive and visually appealing gaming experience by adding dynamic and atmospheric shaders to the game environment.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Ensure the plugin is installed and the server is running.
2. Join a Minecraft world and observe the enhanced night sky effects.
3. In the End dimension, you will see a black hole with a purple aura surrounding it.
